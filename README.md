================================================================================
                    БИБЛИОТЕЧНАЯ СИСТЕМА - ИНСТРУКЦИЯ ПО ПРОВЕРКЕ
================================================================================

1. ЗАПУСК ПРОГРАММЫ
-------------------
- Открыть файл LibraryApp.sln в Visual Studio
- Нажать F5 (или кнопку "Пуск")
- При первом запуске база данных создастся автоматически


2. ТЕСТОВЫЕ УЧЕТНЫЕ ЗАПИСИ
-----------------------------------------
| Логин      | Пароль    | Роль         |
|------------|-----------|--------------|
| admin      | Admin123  | Администратор|
| operator   | Oper123   | Оператор     |
| user       | User123   | Читатель     |
-----------------------------------------

3. ПРОВЕРКА АВТОРИЗАЦИИ И CAPTCHA
---------------------------------
3.1. Обычный вход:
     - Ввести admin / Admin123 → нажать "Вход"
     - Должно открыться главное окно

3.2. CAPTCHA (появляется после 3 ошибок):
     - Ввести любой логин и неверный пароль 3 раза подряд
     - На 3-й раз должна появиться картинка с цифрами (CAPTCHA)

3.3. Блокировка (после 5 ошибок):
     - Продолжить вводить неверный пароль
     - На 5-ю попытку вход заблокируется на 30 секунд


4. ПРОВЕРКА ФУНКЦИЙ ПО РОЛЯМ
----------------------------
4.1. Администратор (admin / Admin123):
     - Доступны: Книги, Читатели, Выдача
     - Во всех разделах есть кнопки: Добавить, Редактировать, Обновить

4.2. Оператор (operator / Oper123):
     - Доступны: Книги, Читатели, Выдача
     - Во всех разделах есть кнопки: Добавить, Редактировать, Обновить

4.3. Читатель (user / User123):
     - Доступны: Книги (только просмотр), Читатели (только свои данные)
     - Кнопок "Добавить" и "Редактировать" НЕТ


5. ПРОВЕРКА РАЗДЕЛА "КНИГИ"
---------------------------
5.1. Просмотр:
     - Нажать "Книги" → открывается таблица с книгами

5.2. Добавление книги (admin или operator):
     - Нажать "Добавить" → заполнить поля → "Сохранить"
     - Новая книга появляется в таблице

5.3. Редактирование книги:
     - Выбрать строку с книгой → нажать "Редактировать"
     - Изменить данные → "Сохранить"
     - Изменения отображаются в таблице


6. ПРОВЕРКА РАЗДЕЛА "ЧИТАТЕЛИ"
------------------------------
6.1. Просмотр (admin или operator):
     - Нажать "Читатели" → виден список всех читателей
     - Колонки: № билета, ФИО, Телефон, Email, Все книги, Статус книг

6.2. Просмотр (user):
     - Войти как user → нажать "Читатели"
     - Видна только своя запись (одна строка)

6.3. Добавление читателя (admin или operator):
     - Нажать "Добавить" → выбрать пользователя из списка
     - Заполнить ФИО, телефон, email
     - Номер билета генерируется автоматически (LIB-001, LIB-002...)
     - Нажать "Сохранить"

6.4. Редактирование читателя:
     - Выбрать строку → нажать "Редактировать"
     - Изменить данные → "Сохранить"


7. ПРОВЕРКА РАЗДЕЛА "ВЫДАЧА"
----------------------------
7.1. Создание выдачи:
     - Нажать "Выдача" → "Новая выдача"
     - Выбрать читателя из списка
     - Выбрать книгу из списка (доступны все книги)
     - Установить дату выдачи и срок возврата
     - Нажать "Сохранить"

7.2. Отметка возврата:
     - Выбрать строку с выдачей → нажать "Возвращена"
     - Статус книги меняется на "Возвращена"

7.3. Отметка утери:
     - Выбрать строку с выдачей → нажать "Утеряна"
     - Статус книги меняется на "Утеряна"

7.4. Редактирование выдачи:
     - Выбрать строку → нажать "Редактировать"
     - Изменить данные → "Сохранить"


8. ПРОВЕРКА РЕГИСТРАЦИИ НОВОГО ПОЛЬЗОВАТЕЛЯ
-------------------------------------------
8.1. На форме входа нажать "Регистрация"
8.2. Заполнить: Логин, ФИО, Телефон, Email, Пароль (не менее 6 символов)
8.3. Нажать "Зарегистрироваться"
8.4. После успешной регистрации появится сообщение и читательский билет

     У созданного пользователя:
     - Роль: "user" (обычный читатель)
     - В разделе "Читатели" видит только свои данные


9. ПРОВЕРКА МОДИФИКАЦИИ (СВОИ СТАТУСЫ)
--------------------------------------
9.1. В разделе "Читатели" есть колонка "Статус книг":
     - ✅ Возвращена
     - ❌ Утеряна
     - 📖 Выдана
     - (пусто) если книг нет

9.2. Номер читательского билета генерируется автоматически:
     - LIB-001, LIB-002, LIB-003...


10. ПРОСМОТР БАЗЫ ДАННЫХ (SQLite)
---------------------------------
База данных находится в файле: MyLibraryDB.sqlite
Путь: папка проекта → bin → Debug → MyLibraryDB.sqlite

10.1. Онлайн-просмотр (без установки):
     - Перейти на сайт: https://sqlime.org/
     - Перетащить файл MyLibraryDB.sqlite в окно браузера
     - Слева появится список таблиц


10.2. Таблицы в базе данных:
     | Таблица        | Содержание                              |
     |----------------|-----------------------------------------|
     | Users          | Пользователи (логин, пароль, роль)      |
     | Roles          | Роли (admin, operator, user)            |
     | Readers        | Читатели (ФИО, телефон, email, билет)   |
     | Books          | Книги (название, автор, статус)         |
     | BookStatuses   | Статусы книг (В наличии, Выдана, и т.д.)|
     | BookLendings   | Выдача книг (дата выдачи/возврата)      |
     | LoginAttempts  | Журнал попыток входа                    |

10.3. ВАЖНО:
     - Перед открытием базы данных в sqlime.org закройте программу
     - Иначе файл будет заблокирован и не откроется


11. ЗАВЕРШЕНИЕ РАБОТЫ
---------------------
- Нажать кнопку "Выход" в главном окне
- Или закрыть окно программы
